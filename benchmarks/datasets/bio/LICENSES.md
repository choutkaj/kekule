# Biomolecule dataset sources and licences

Every file is an unmodified wwPDB versioned-archive mmCIF
(`pdb_0000XXXX_xyz_vM-m.cif.gz`), named by entry and revision, as served by
[files-versioned.wwpdb.org](https://files-versioned.wwpdb.org/). `manifest.jsonl`
gives each file's URL and SHA-256, and `selection.lock.json` records the RCSB
Search API pools selection drew from.

PDB archive data are released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) by the
[wwPDB](https://www.wwpdb.org/about/usage-policies). Please cite the wwPDB
consortium, *Nucleic Acids Res.* 47, D520 (2019), and the primary citation of
each entry.
