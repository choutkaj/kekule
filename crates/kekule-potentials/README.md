# kekule-potentials

`kekule-potentials` provides concrete potentials for topology-bound [`kekule`](https://crates.io/crates/kekule) structural views. Its default `openff` feature evaluates OpenFF energies and gradients from a `kekule-openff` parameterization, and every potential can be minimized with L-BFGS.

## Installation

```sh
cargo add kekule-potentials
```
