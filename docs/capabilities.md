# Current capabilities

This is the entry point for current support boundaries; detailed contracts live
beside their implementations, linked below.

| Area | Current support and boundaries | Authoritative contract |
| --- | --- | --- |
| Chemistry ownership | Connected molecules; systems, coordinates, and derived perception have separate owners; hierarchy views (molecules, chains, residues, atom sites, atoms) indexed once per published topology | [Specification](../SPEC.md) |
| Aromaticity | RDKit 2026.03.3 electron counting (default and MDL models), fused subsets up to six rings; default perception marks whole fused systems where RDKit marks only perimeters; MDL (for OpenFF) follows RDKit exactly; localized bonds unchanged | [Model](../crates/kekule/src/molecule/perception.rs), [aromaticity](../crates/kekule/src/algorithms/aromaticity.rs) |
| Conjugation and resonance | RDKit 2026.03.3 conjugation and charge-move resonance delocalization in default perception; explicit bounded contributor enumeration with all five RDKit flags; source chemistry unchanged | [Guide](resonance.md), [conjugation](../crates/kekule/src/algorithms/conjugation.rs), [resonance](../crates/kekule/src/algorithms/resonance.rs) |
| Measurements | Cartesian distances, angles, and signed dihedrals; optional consecutive-bond validation; deterministic bond dihedrals (CIP priority, atom-ID ties); periodic preprocessing is explicit | [Measurement contract](../crates/kekule/src/structure/measure.rs), [bond dihedrals](../crates/kekule/src/structure/measure/bond_dihedrals.rs) |
| Builder placement | On a `StructureEditor` draft: hydrogen completion and collapse, ideal bond lengths and atom shapes, single atoms and 48 named fragments attached or placed as new molecules, systematic atom naming; no conformer generation or relaxation | [Placement](../crates/kekule/src/structure/placement.rs) |
| Geometry editing | Distance, angle, and dihedral setters; reusable topology-bound edits with automatic or explicit moving selections; translation, rotation, and rigid transforms; stored Cartesian coordinates only, without relaxation or ring-closure solving | [Geometry editing contract](../crates/kekule/src/structure/geometry_edit.rs) |
| Structural editing | Molecule, topology, and structure editors with stable draft handles and transactional publication; untouched definitions shared with earlier snapshots; source-to-published maps of atoms, bonds, residues, and chains; perception redone only for changed definitions | [Topology editing](../crates/kekule/src/topology/editor.rs), [publication](../crates/kekule/src/topology/editor/publication.rs), [structure editing](../crates/kekule/src/structure/structure_editor.rs) |
| Selections | Snapshot-bound atom and bond sets; checked picking and construction from sorted indices or bit masks, set algebra, hierarchy and graph expansion, predicates, query matches, and Cartesian proximity | [Atom selection contract](../crates/kekule/src/topology/selection.rs), [bond selection contract](../crates/kekule/src/topology/selection/bonds.rs), [spatial selection](../crates/kekule/src/structure/measure.rs) |
| Selection language | VMD/PyMOL/MDAnalysis-style text over atom, residue, chain, molecule, chemistry, and hydrogen terms, macros, grid-based `within`, and expansion; canonical printing; typed errors with spans; host resolver; conformance suite and fuzzing | [Grammar](selection-language.md), [public API](../crates/kekule/src/lib.rs) |
| Element reference data | Symbols, Cordero covalent radii, dipole polarizabilities; van der Waals radii from Charry–Tkatchenko (free-atom default and reference, falling back to each other), Bondi 1964, Mantina, and Alvarez columns, which never fall back | [Radius sources and coverage](../crates/kekule/src/molecule/element_reference.rs) |
| Hydrogens | Explicit graph atoms and implicit counts; fixed counts survive reperception; conversions preserve information and stereo, on molecules and on structure drafts | [Hydrogen semantics](hydrogen-semantics.md) |
| SMILES | Parsing, interpretation, plain/isomeric/canonical writing, and supported CX radical/group input and tetrahedral group output; unsupported content fails explicitly | [Public format API](../crates/kekule/src/lib.rs), [stereo support](stereo-support.md) |
| SMARTS | Recursive queries, Boolean atom/bond logic, connectivity/valence/ring predicates, tetrahedral and alkene stereo, enhanced tetrahedral groups, tagged and topology matching | [Dialect and explicit exclusions](../crates/kekule/src/query/dialect.md) |
| Stereo/CIP | Represented tetrahedral, double-bond and atropisomer stereo; bounded CIP assignment; explicit cleanup and candidate detection remain separate operations | [Stereo support](stereo-support.md), [CIP options](../crates/kekule/src/algorithms/cip/mod.rs) |
| MOL/SDF | Independent records, V2000/V3000 reading and writing with automatic version selection; explicit unsupported-content errors; structure sets as records carrying each geometry's step or coordinate, read back in that order | [MOL/SDF writer](../crates/kekule/src/io/molfile/write.rs) |
| mmCIF | Independent blocks, altloc selection and overrides, coordinate models as structure sets, hierarchy/source reports; output states only bonds templates do not imply; metal coordination kept as report metadata, not bonds; fixed implicit-hydrogen counts fail unless omitted | [Alternate locations](mmcif-alternate-locations.md), [interpretation](../crates/kekule/src/io/macromolecular/mod.rs), [writer](../crates/kekule/src/io/mmcif/write.rs) |
| PDB | One entry as typed records with hybrid-36 numbers; models, coordinate models, and conformations through the mmCIF pipeline; round-tripping writer; content PDB cannot carry fails explicitly or, where allowed, is omitted with a report | [Public format API](../crates/kekule/src/lib.rs), [records](../crates/kekule/src/io/pdb/document.rs), [interpretation](../crates/kekule/src/io/macromolecular/pdb.rs), [writer](../crates/kekule/src/io/pdb/write.rs) |
| Biological assemblies | mmCIF and PDB `REMARK 350` assemblies as interpretation report records with operator expressions expanded; unreadable assemblies left out and reported; assemblies built as structures of copies; stored in native files | [Assemblies](../crates/kekule/src/io/macromolecular/assemblies.rs), [native format](native-format.md) |
| XYZ | Frames as a structure or structure set; connectivity inferred from Cordero radii plus 0.45 Å as single or dative bonds; no bond orders, charges, or stereo; extended columns rejected unless reported omitted; reading only | [Public format API](../crates/kekule/src/lib.rs), [interpretation](../crates/kekule/src/io/xyz/interpret.rs) |
| Native format | Exact, versioned binary persistence of molecules, topologies, structures, structure sets, ensembles, and interpretation reports; optional stored perception validated on load; streaming, bounded, fuzzed decoding | [Specification](native-format.md), [public API](../crates/kekule/src/lib.rs) |
| Trajectories | Fixed-topology XYZ/DCD/TRR/XTC streaming without copying; verified random access via portable frame indexes; growing-file following and restart continuation; periodic transformations, imaging, streaming superposition; content a format cannot carry rejected or omitted with a report | [Trajectory I/O](../crates/kekule/src/traj/io/mod.rs), [periodic operations](../crates/kekule/src/traj/periodic.rs), [analysis](../crates/kekule/src/traj/analysis.rs) |
| Weighted statistics | Per-atom RMSF and contact occupancy of atom pairs or groups over explicitly weighted structures; streaming, mergeable accumulators with the same result for any parallel split; coordinates as stored, without imaging | [Statistics](../crates/kekule/src/statistics.rs) |
| Non-covalent interactions | Hydrogen bonds, salt bridges, π stacking, cation–π, halogen bonds, metal coordination, and hydrophobic contacts with adjustable literature-default criteria; weighted hydrogen-bond occupancy; no imaging; protonation from represented chemistry, not predicted | [Interactions](../crates/kekule/src/interactions/mod.rs), [criteria](../crates/kekule/src/interactions/criteria.rs), [features](../crates/kekule/src/interactions/features.rs) |
| Alignment | Kabsch fits, RMSD, and aligned RMSD over selections or atom correspondences (explicit pairs, dense order, or hierarchy labels); symmetry-corrected fits within explicit search limits; no imaging of periodic coordinates | [Alignment](../crates/kekule/src/alignment.rs), [correspondence](../crates/kekule/src/alignment/correspondence.rs), [labels](../crates/kekule/src/alignment/correspondence/labels.rs), [symmetry](../crates/kekule/src/alignment/symmetry.rs) |
| Structure sets | Copy-on-write geometries of one topology with optional per-atom state and an order (times, steps, or coordinate values); ensembles with distributions; RMSD, RMSF, contact occupancy, and leader, hierarchical, and k-medoids clustering; read, written, and stored natively | [Structure sets](../crates/kekule/src/structure/structure_set.rs), [symmetry](../crates/kekule/src/alignment/symmetry.rs), [clustering](../crates/kekule/src/clustering.rs), [hierarchical clustering](../crates/kekule/src/clustering/hierarchical.rs), [k-medoids](../crates/kekule/src/clustering/medoids.rs), [statistics](../crates/kekule/src/statistics.rs) |
| Structure sets read from files | Sets over indexed XYZ, DCD, TRR, or XTC files, holding no geometries in memory; decoded on read, refreshed as files grow, lazily processed; results equal the in-memory set; no threads or geometry cache in kekule | [Structure set readers](../crates/kekule/src/structure/structure_set/read.rs), [indexed files](../crates/kekule/src/traj/io/indexed_file.rs), [processing](../crates/kekule/src/traj/processed.rs) |
| Sequences | One-letter codes of polymer monomers from a caller's library, bundled templates, or the Chemical Component Dictionary, modified residues taking parents' letters; chain sequences; mmCIF polymer entity sequences; PDB `SEQRES` is not read | [Sequences](../crates/kekule/src/sequence.rs), [entity sequences](../crates/kekule/src/io/macromolecular/sequences.rs) |
| DSSP | Read-only analysis of a structure's coordinates; conformer, residue eligibility, and chain policies matter to reference comparisons; optional multithreaded assignment identical to single-threaded; per-layout plans for frames | [Analysis contract](../crates/kekule/src/dssp/mod.rs), [executors](../crates/kekule/src/parallel.rs) |
| Solvation | Periodic box sizing, TIP3P water packing, monovalent counterions and salt, named as the Chemical Component Dictionary names them so solvated systems round-trip through PDB and mmCIF; no force-field assignment or equilibration | [Solvation contract](../crates/kekule/src/solvation/solvent.rs), [box sizing](../crates/kekule/src/solvation/solvent/boxes.rs) |
| Potentials | Topology-bound energy/gradient contract; OpenFF evaluation in vacuum without cutoffs (periodic cells rejected, constraints not applied); L-BFGS minimization with optional fixed atoms and harmonic position restraints | [Potential contract and singular-geometry policy](../crates/kekule-potentials/src/lib.rs), [OpenFF capabilities](../crates/kekule-potentials/src/openff.rs), [minimizer](../crates/kekule-potentials/src/minimize.rs) |
| OpenFF | Bundled Rosemary and Ash, or compatible OFFXML rule sets and NAGL bundles; typed topology-bound parameters, distance constraints, library charges, native NAGL CPU inference with model identity checks; no molecule size limit; explicit H required | [OpenFF contract](../crates/kekule-openff/CONTRACT.md) |

The PDB, mmCIF, Molfile, SDF, and `kekule::traj` writers return a `WriteReport`
naming every omission an `UnrepresentablePolicy::Omit` made; the XYZ writer also
names content XYZ can never carry.

The DSSP investigation and force-field scalability/periodicity extensions remain
deferred. Raw reference disagreements are not automatically defects, but
comparisons must not discard asserted fields or relabel errors as agreements.

For maintenance validation, see [CI](../.github/workflows/ci.yml) and
[fuzzing](../FUZZING.md). The [scientific benchmark](../benchmarks/README.md)
compares Kekule with RDKit, gemmi, Biotite and mkdssp; its
[known differences](../benchmarks/known-differences.toml) record current gaps and
intended policies. It is never a release gate.

The retired OpenFF [validation report](https://github.com/choutkaj/kekule/blob/ead90ca94f66e6b4f3082e5db49d6ddc042cc32c/benchmarks/openff/VALIDATION.md)
records results at its revision; the crate contract defines current support.
